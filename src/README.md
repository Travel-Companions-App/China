# Исходники разговорника и тренажёра

Из одного источника данных собираются два результата:
- `../China_razgovornik.pdf` — офлайн-PDF под экран iPhone (95×200 мм);
- `../index.html`, `../sw.js`, `../manifest.webmanifest` — офлайн-тренажёр (PWA) на GitHub Pages.

## Файлы

| Файл | Что внутри |

| `data.py` | Все данные: карточки «показать», заготовка карточки места `PLACE_CARD`, фразы, вывески, цифры, вокзалы, шпаргалка `TIPS` |
| `lessons.py` | Самоучитель: 8 уроков (теория + упражнения: выбор, сборка фразы, тон на слух, перевод на слух, цены на слух) |

## Как добавить фразу

1. В `data.py` добавить строку `("汉字", "pīnyīn с тонами", "перевод")` в нужный раздел `PHRASES` (или в `SIGNS`, `SHOW_CARDS`). Кириллицу руками не писать — она генерируется.
2. `./build.sh` — должно закончиться `ИТОГ: OK`.
3. Закоммитить и запушить в `main`. Через 1–2 минуты GitHub Pages обновит сайт.
4. На iPhone один раз открыть тренажёр при интернете (закрыть и открыть снова), чтобы обновился офлайн-кэш.

## Уроки, справочник

- Формат блоков описан в шапке каждого файла. Кириллицу не писать — генерируется.
- Варианты тонов в упражнении `T(...)` строятся автоматически из pinyin.
- Слова из теории уроков (`E(...)`) автоматически попадают в «Карточки» отдельными колодами.
- Справочник: каждый факт — с источником и датой; несверенное помечать `[из памяти]`. В PDF справочник идёт отдельным разделом.
- Прогресс хранится на устройстве (`localStorage`, ключи `cn:*`): `srs` — интервальное повторение (ящики 0–5, интервалы 0/1/3/7/16/35 дней; старый `known` переносится), `favs` — избранное, `my` — свои фразы, `places` — мои места (при первом запуске переносятся из старого `trips`), `recent` — недавние, `les` — уроки, `theme`, `fz`. Офлайн-кэш их не трогает; копия — «Настройки → Сохранить копию».

## Обновление на телефоне

`sw.js` ставит новую версию в фоне (`skipWaiting` + `clients.claim`), страница ловит `controllerchange` и показывает «Доступна новая версия → Обновить». Проверка — при запуске и при возврате в приложение, если есть сеть.

## «Мои фразы» и Claude

Без API-ключа: кнопка копирует запрос в буфер и открывает `https://claude.ai/new?q=…`. Параметр `q` не документирован Anthropic — если поле пустое, пользователь вставляет запрос из буфера. Ответ в формате `汉字 | pinyin | русский` разбирается построчно (маркеры списков, нумерация и `` ` `` игнорируются); слова pinyin, которые не раскладываются на слоги, подсвечиваются.

## Правила транскрипции

Кириллица приблизительная, без тонов (тон виден в pinyin).

- j / q / x → дз / ч / с + мягкая гласная (дзи, чи, си, ся, сье); zh / ch / sh / r → дж / ч / ш / ж + твёрдая (джа, чу, шы).
- -i после zh ch sh r z c s → «ы» (шы, дзы, сы).
- -n → «н» (ман, эн, ин, ун); -ng → «нг», «г» не выговаривается (манг, тинг, донг).
- -ian / yan → «ьен» / «йен» (дьен, сьен); -ong → «онг»; -iong → «ёнг»; -iu / you → «ёу».
- ü → «юй» (нюй, чюй); üe → «юэ»; üan → «юэн».
- e → «э» (гэ, дэ); ui → «уэй»; uo → «уо».

`check.py` гарантирует, что у разных слогов разная кириллица.

## Известные ограничения

- В беззвучном режиме iOS кнопка 🔊 в тренажёре молчит: Safari глушит синтез речи сайтов. Проверено на `../diag.html`: обходы через `navigator.audioSession.type = "playback"` и фоновый `<audio>` не помогли. В беззвучном режиме работает только системное «Speak» при выделении текста в PDF (Settings → Accessibility → Read & Speak).
- Для озвучки нужен китайский голос iOS (у пользователя — Tingting).
- Включать GitHub Pages и создавать репозитории из сессии Claude нельзя (прокси); push работает через Claude GitHub App. Теги через прокси сессии не пушатся — точка отката оформляется веткой (`stable-v1`).
- `robots.txt` для проекта на `github.io` не работает (краулеры читают его только из корня домена); `sitemap.xml` подаётся вручную в Google Search Console / Яндекс.Вебмастер.
- Screen Wake Lock в установленном PWA на iOS работает с iOS 18.4; на старых версиях экран может гаснуть.
