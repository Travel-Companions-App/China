# Исходники разговорника и тренажёра

Из одного источника данных собираются два результата:
- `../China_razgovornik.pdf` — офлайн-PDF под экран iPhone (95×200 мм);
- `../index.html`, `../sw.js`, `../manifest.webmanifest` — офлайн-тренажёр (PWA) на GitHub Pages.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.py` | Все данные: отель, карточки «показать», фразы, вывески, цифры, вокзалы, шпаргалка `TIPS` |
| `translit.py` | Pinyin → кириллица «как слышится»: список 406 слогов, правила, разбор слов на слоги |
| `build_pdf.py` | Сборка PDF через wkhtmltopdf (шрифт Noto Sans CJK SC) |
| `build_pwa.py` | Сборка тренажёра: данные с кириллицей вшиваются в `pwa_template.html`; версия кэша `sw.js` = хеш страницы |
| `pwa_template.html` | Интерфейс тренажёра: вкладки Показать / Карточки / Тест / Фразы / Слоги |
| `check.py` | Проверки после сборки |
| `build.sh` | Сборка + проверки одной командой |

## Как добавить фразу

1. В `data.py` добавить строку `("汉字", "pīnyīn с тонами", "перевод")` в нужный раздел `PHRASES` (или в `SIGNS`, `SHOW_CARDS`). Кириллицу руками не писать — она генерируется.
2. `./build.sh` — должно закончиться `ИТОГ: OK`.
3. Закоммитить и запушить в `main`. Через 1–2 минуты GitHub Pages обновит сайт.
4. На iPhone один раз открыть тренажёр при интернете (закрыть и открыть снова), чтобы обновился офлайн-кэш.

## Правила транскрипции

Кириллица приблизительная, без тонов (тон виден в pinyin).

- j / q / x → дз / ч / с + мягкая гласная (дзи, чи, си, ся, сье); zh / ch / sh / r → дж / ч / ш / ж + твёрдая (джа, чу, шы).
- -i после zh ch sh r z c s → «ы» (шы, дзы, сы).
- -n → «н» (ман, эн, ин, ун); -ng → «нг», «г» не выговаривается (манг, тинг, донг).
- -ian / yan → «ьен» / «йен» (дьен, сьен); -ong → «онг»; -iong → «ёнг»; -iu / you → «ёу».
- ü → «юй» (нюй, чюй); üe → «юэ»; üan → «юэн».
- e → «э» (гэ, дэ); ui → «уэй»; uo → «уо».

`check.py` гарантирует, что у разных слогов разная кириллица.

## Известные ограничения

- В беззвучном режиме iOS кнопка 🔊 в тренажёре молчит: Safari глушит синтез речи сайтов. Проверено на `../diag.html`: обходы через `navigator.audioSession.type = "playback"` и фоновый `<audio>` не помогли. В беззвучном режиме работает только системное «Speak» при выделении текста в PDF (Settings → Accessibility → Read & Speak).
- Для озвучки нужен китайский голос iOS (у пользователя — Tingting).
- Включать GitHub Pages и создавать репозитории из сессии Claude нельзя (прокси); push работает через Claude GitHub App.
