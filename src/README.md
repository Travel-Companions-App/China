# Исходники разговорника и тренажёра

Из данных в `src/` собирается офлайн-тренажёр:
- `../index.html`, `../sw.js`, `../manifest.webmanifest` — офлайн-тренажёр (PWA) на GitHub Pages.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.py` | Все данные: карточки «показать», заготовка карточки места `PLACE_CARD`, фразы, вывески, вокзалы, шпаргалка `TIPS` |
| `lessons.py` | Самоучитель: 12 уроков по ситуациям (теория + упражнения: выбор, сборка фразы, тон на слух, перевод на слух, цены на слух) |
| `guide.py` | Справочник «Жизнь в Китае»: статьи, фразы, источники с датами (`CHECKED` — дата сверки) |
| `translit.py` | Pinyin → кириллица «как слышится»: список 406 слогов, правила, разбор слов на слоги |
| `build_pwa.py` | Сборка тренажёра: данные с кириллицей вшиваются в `pwa_template.html`; SEO-метки, `manifest`, `sitemap.xml`; версия кэша `sw.js` = хеш страницы. Дата версии хранится в `.build_stamp` и меняется только при изменении контента |
| `pwa_template.html` | Интерфейс: Главная (поиск, кнопки, избранное, недавние) / Словарь (разделы по алфавиту; вокзалы — в «Поезде») / Показать / Ещё (Мои места, Мои фразы, Карточки, Тест, Справка, Уроки, Слоги, Помощь, Настройки). Вводный гайд при первом запуске, «Что нового» после обновления (`APP_REV`, `CHANGES`). «Назад» — через History API: переходы вглубь пишутся `pushState`, системный свайп от края iOS приходит как `popstate`. Перевод pinyin → кириллица в JS использует таблицу слогов из сборки — правила те же, что в `translit.py` |
| `check.py` | Проверки после сборки: транскрипция, pinyin всех данных, структура уроков, источники в справке, JS |
| `build.sh` | Сборка + проверки одной командой |
| `e2e.py` | Сквозной тест в headless Chromium: вводный гайд, главная (поиск, недавние, избранное, подсказки, ＋), Словарь, жесты (назад, свайп-удаление), показ, «Мои места» (перенос из старой «Поездки», добавление, правка, удаление), все уроки, справка, карточки, «Мои фразы» (совпадение кириллицы JS и Python), тема, «Что нового», офлайн, баннер обновления, полный сброс. `--shots` — скриншоты в `../docs/screenshots/` |
| `og.py` | Картинка превью ссылки `../og.png` |
| `../.github/workflows/check.yml` | CI: сборка, проверка, что `index.html` пересобран, сквозной тест |

## Что нового

При каждом выпуске с заметными изменениями: увеличить `APP_REV` в `pwa_template.html` и добавить запись в `CHANGES` (коротко, для пользователя). Пользователь увидит записи от своей версии до текущей один раз после обновления.

## Как добавить фразу

1. В `data.py` добавить строку `("汉字", "pīnyīn с тонами", "перевод")` в нужный раздел `PHRASES` (или в `SIGNS`, `SHOW_CARDS`). Кириллицу руками не писать — она генерируется.
2. `./build.sh` — должно закончиться `ИТОГ: OK`.
3. Закоммитить и запушить в `main`. Через 1–2 минуты GitHub Pages обновит сайт.
4. На iPhone один раз открыть тренажёр при интернете (закрыть и открыть снова), чтобы обновился офлайн-кэш.

## Уроки, справочник

- Формат блоков описан в шапке каждого файла. Кириллицу не писать — генерируется.
- Варианты тонов в упражнении `T(...)` строятся автоматически из pinyin.
- Слова из теории уроков (`E(...)`) автоматически попадают в «Карточки» отдельными колодами.
- Справочник: каждый факт — с источником и датой; несверенное помечать `[из памяти]`.
- Прогресс хранится на устройстве (`localStorage`, ключи `cn:*`): `quick` — кнопки главной, `homeLayout` — порядок и видимость блоков главной, `voice` / `rate` — выбранный голос и скорость, `hidden` — скрытые карточки («Знаю — не показывать»; старые `srs`/`known` удаляются при запуске), `pyf` — pinyin на лицевой стороне, `favs` — избранное, `my` — свои фразы, `places` — мои места (при первом запуске переносятся из старого `trips`), `recent` — недавние, `les2` — уроки (с ред. 12; старый `les` удаляется), `onboarded` — вводный гайд показан, `ver` — последняя редакция, для которой показано «Что нового», `theme`, `fz`. Офлайн-кэш их не трогает; копия — «Настройки → Сохранить копию».

## Обновление на телефоне

`sw.js` ставит новую версию в фоне (`skipWaiting` + `clients.claim`), страница ловит `controllerchange` и показывает «Доступна новая версия → Обновить». Проверка — при запуске и при возврате в приложение, если есть сеть.

## «Мои фразы» и Claude

Без API-ключа: кнопка копирует запрос в буфер и открывает `https://claude.ai/new?q=…`. Параметр `q` не документирован Anthropic — если поле пустое, пользователь вставляет запрос из буфера. Ответ в формате `汉字 | pinyin | русский` разбирается построчно (маркеры списков, нумерация и `` ` `` игнорируются); слова pinyin, которые не раскладываются на слоги, подсвечиваются.

## Правила транскрипции

Кириллица приблизительная, без тонов (тон виден в pinyin).

- j / q / x → дз / ч / с + мягкая гласная (дзи, чи, си, ся, сье); zh / ch / sh / r → дж / ч / ш / ж + твёрдая (джа, чу, шы).
- -i после zh ch sh r z c s → «ы» (шы, дзы, сы).
- -n → «н» (ман, эн, ин, ун); -ng → «нг», «г» не выговаривается (манг, тинг, донг).
- -ian / yan → «ьен» / «йен» (дьен, сьен); -ong → «онг»; -iong → «ёнг»; -iu / you → «ёу».
- ü → «юй» (нюй, чюй); üe → «юэ»; üan → «юэн».
- e → «э» (гэ, дэ); ui → «уэй»; uo → «уо».

`check.py` гарантирует, что у разных слогов разная кириллица.

## Известные ограничения

- В беззвучном режиме iOS кнопка 🔊 в тренажёре молчит: Safari глушит синтез речи сайтов. Проверено на `../diag.html`: обходы через `navigator.audioSession.type = "playback"` и фоновый `<audio>` не помогли. В беззвучном режиме работает только системное «Speak» при выделении текста (Settings → Accessibility → Read & Speak).
- Для озвучки нужен китайский голос iOS (у пользователя — Tingting).
- Включать GitHub Pages и создавать репозитории из сессии Claude нельзя (прокси); push работает через Claude GitHub App. Теги через прокси сессии не пушатся — точка отката оформляется веткой (`stable-v1`).
- `robots.txt` для проекта на `github.io` не работает (краулеры читают его только из корня домена); `sitemap.xml` подаётся вручную в Google Search Console / Яндекс.Вебмастер.
- Screen Wake Lock в установленном PWA на iOS работает с iOS 18.4; на старых версиях экран может гаснуть.
