# Заметки разработки

Справочные детали, которые не нужны в каждой сессии. Основное — `src/README.md`.

## Данные и форматы
- Ключи `localStorage` (префикс `cn:`): `quick`, `homeLayout`, `favs`, `recent`, `hidden`, `pyf`, `my`, `places`, `trips` (старый), `les2`, `onboarded`, `ver`, `voice`, `rate`, `theme`, `fz`, `deck`.
- `cn:quick`: `{k:"walk"}` | `{k:"taxi"}` | `{k:"place",id}` | `{k:"place",id,m:"walk"}` | `{k:"show",id}` | `{k:"card",c:снимок}`. При `cn:ver` < 14 `{k:"taxi"}` однократно заменяется на `{k:"walk"}`.
- `cn:homeLayout` = `{order, off}`; без ключа — `DEF_OFF` (избранное выключено); один блок всегда виден.
- id карточек: фраза — `раздел|汉字`; места — `place:` (такси), `walk:` (как пройти); `remapIds` переносит id переехавших фраз в `cn:favs` / `cn:hidden`.
- Резервная копия — JSON, метка `app: "travel-companions-china"`.
- Смена адреса сайта = другой origin: данные не переносятся (только через копию). Хранилище иконки «Домой» отдельно от Safari (WebKit bug 181849, 01.02.2022). GitHub Pages при переименовании не перенаправляет.
- SHA до ред. 14 недействительны (история переписана); прежние репозитории удалены или выключаются, редиректа нет.

## Технические ограничения
- Wake Lock в установленном PWA на iOS — с iOS 18.4. Свайп «назад» в PWA — через `pushState`; `touch-action: manipulation` отключает зум двойным тапом (по отчётам). Оба — проверить на iPhone.
- Голос: Safari Web Speech API на iOS отдаёт только предустановленные голоса (Apple Developer Forums, тред 723503, янв. 2023).
- `robots.txt` для проектного сайта на github.io не читается (только из корня `*.github.io`); индексация — Search Console / Яндекс.Вебмастер + `sitemap.xml`.
- Playwright: `page.evaluate` вызывает выражение, если оно возвращает функцию (помощник свайпа — через `add_init_script`); баннер «Доступна новая версия» закрывает нижний пункт «Ещё».
- `git filter-repo` — клоном `github.com/newren/git-filter-repo`; после force-push старые коммиты доступны по SHA до чистки через GitHub Support.
- Push в пустой репозиторий пишет `expected 'acknowledgments'` / `push negotiation failed` — push проходит, проверять `git ls-remote`.

## Текстовый разговорник (только по запросу автора)
Генерация из `data.py` / `guide.py` / `lessons.py` через `translit.to_cyr`. Структура: `# Разговорник (база для туриста)` + строка версии; `## Карточки «показать»` (`SHOW_CARDS`: `### title`, `"".join(zh)`, `*py*`, кириллица, `ru`); `## Фразы: <раздел>`; `## Вывески: <группа>` (4-й элемент `SIGNS`, порядок появления); `## Вокзалы`; `## Справочник «Жизнь в Китае» (сверено CHECKED)` + `## Справка: <статья>` по `GUIDE[*].phrases`; `## Уроки (только в тренажёре)` (`N. title — goal`). Таблицы `| 汉字 | pinyin | кириллица | русский |`.

## Рынок (обзор 23.10.2026)
- Прямые конкуренты: EasyChinaTalk (PWA, 200+ фраз, en/ru/es, $5.9, синтезированная озвучка), Handarin (149 фраз, аудио носителей), Hello Pal Chinese Phrasebook (2000+ фраз), небольшие русские разговорники в App Store (кириллица), Jourist «Разговорник» (латиница), MeiLin (видеокурс), Lorti/phrasebook (открытый PWA для японского).
- Косвенные: Apple Translate, Baidu / Microsoft Translator (работают в Китае без VPN), Alipay (встроенный перевод), Pleco.
- Отличия: кириллица + pinyin с тонами, поиск в 4 системах ввода, «слышите в ответ», справочник с источниками, «Мои места» → карточки, бесплатно и открыто.
- Слабые места: голос iOS (молчит в беззвучном), нет перевода произвольной фразы, не в сторах, Android не тестирован, нет вычитки носителем.
